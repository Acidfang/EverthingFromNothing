# Thought Resolution

## What it is

A thought is represented as a change in an observer field:

```text
WAS: distinction d is not present
IS:  distinction d is present
```

Therefore:

```text
IS(ME) != WAS(ME)
```

The thought is not declared identical to an external thing. It is the actual
presence of a representation within the observer that resolves it.

Resolving the same distinction again does not create a duplicate identity. It
increments the recursive resolution history of that distinction.

Thinking about a prior thought creates another addressable distinction:

```text
ME resolves X
ME resolves thought(X)
ME resolves thought(thought(X))
...
```

## What it allows

The executable thought ledger distinguishes:

- first appearance of a represented Difference;
- maintained availability of that Difference;
- repeated resolution;
- a thought becoming the NOT ME of another thought;
- WAS and IS for every local thought event.

Within this formalization:

```text
learning = a Difference becoming maintainable by ME
memory   = IS retaining access to a prior resolution
```

These are definitions inside the modeller. Relationships to biological
observations can be compared only after the observations and mapping operation
are stated.

## Projection is not identity

Recursive six-Face lineage and observer projection are stored as different
relations.

An ordered Face path is a causal identity:

```text
A = (f0, f1, ..., fn)
```

The binary-scaled position is:

```text
p(A) = sum(2^k fk)
```

At depth `n`, the selected construction contains exactly:

```text
6^n
```

distinct paths and positions. A normalized display may relate several
presentations, but the display relation does not erase their ancestry.
