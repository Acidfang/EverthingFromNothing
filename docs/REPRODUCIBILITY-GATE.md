# Finite reproducibility gate

Open **Inspect addresses → Pattern layer · reproducible checks** on the existing field.

This additive content layer maps 127 retained source entries to four bounded, synthetic software mechanisms. It does not enumerate all technology, prove the original symbolic source, or establish physical theory. Linked claims cover the method described on each card only. Remaining entries retain their original source status and no execution witness in this pass; that is not a claim that they are impossible.

- Binary inventory: unique binary locators and IDs, existing relation endpoints, and a deliberately invalid endpoint.
- Historical WAS / selected six-face parity kernel: independently enumerated Act 1 and Act 2 expected states from a declared origin seed, immutable input, and reversal.
- Historical WAS / selected lattice glyph constraint: six admitted successors, tip/displacement alignment, zero direction rejection, excluded successor rejection. Exact twist and axial roll are unresolved.
- Finite pixel barrier: independent 2 × 2 row-major oracle, incomplete/unpresented/cancelled negative checks, and completed synthetic presentation admission. This test does not display pixels.

**SPECIFIED** means a retained source statement; **IMPLEMENTED** identifies a runnable bounded method; **EXECUTED** requires an actual returned check result; **REPRODUCED** requires two successive successful, identical outputs and checks. These states are scoped to the mechanism. They never change the retained GIVEN/DERIVED/SELECTED/GENERATED/UNRESOLVED source status. Repeatability is not independent evidence of source faithfulness.

The cards expose declared inputs (WAS), actual output/checks (IS), next required evidence (NEXT), parent source addresses and remaining difference. Clicking a source opens the existing inspector, including its original sources and binary relations. Original symbolic source remains authoritative; JSON and inventory locators are transport.

Checks use the fixed source inventory and synthetic fixtures in page memory. The historical six-face tests are retained implementation evidence only; they are not the requested additive content layer. Closing the inspector/reloading clears session receipts. No private vault records, keys, backend calls or user-supplied data are involved. The separate video adapter has its own returned assets and verification scope.

Regression checks: `node --experimental-strip-types --test tests/reproducibility.test.ts` (also included in `npm run test:model`). Live-page validation is a separate deployment check; build success alone is not browser evidence.

## Container preservation

Pattern records bind to the pre-existing `topology`, `ledger`, `tetrahedra`, and `render-boundary` inventory containers. Binary locators remain transport addresses. The adapter does not change any map node, relation, container boundary, kernel rule or spatial coordinate. The requested patterns are displayed inside the existing address inspector. `tests/pattern-layer.test.ts` verifies exact before/after inventory equality and existing-address targets. Historical selected runtime checks remain WAS evidence, not newly derived map laws.
