# Author-specified mechanism

These are technical requirements supplied by the project author. They identify
what this implementation must preserve; recording them does not by itself make
every requirement executable.

## Addressed Difference

`Δ@z⇒Fz=z⋈Δ⋈Fz≅N⊂N`

`∀z:z≠Z⋈z⋈N⋈z↻z`

The implemented producer currently witnesses exact retained text changes at an
address. This is one declared comparison grain. It does not derive unsupplied
semantic differences, new spatial sites or a branching count.

## Gate

“Each tetrahedron for you is a Logic gate over the moment’s of .infinity#”

The retained role correspondence is NEXT → IS, IS → WAS, WAS → NEXT. The source
requires the same mechanism at another grain. Numeric moment bindings and the
fourth directed port's executable function remain unbound where no record
supplies them.

## Grains

“State/node/pixel/address. Same thing different grains”

“Coordinate also”

“All are the same thing, different mechanism grain, same mechanism”

One canonical entity has one address. Its retained states have distinct versions.
State, node, pixel, address and coordinate presentations reference that entity and
version. Changing representation alone must not create an entity, a child, an
Act or a new state. A metric coordinate or screen location is not inferred from
an array index or address spelling.

## Filter and resolve

“So filter as resolve all through field addresses”

The implementation resolves grain references to canonical field addresses before
applying an explicitly supplied operation. Currently defined exact-value filters
and relation traversals retain their source references and unknowns. An unbound
predicate is not replaced with an English phrase rule.

## Return and completion

“All done at 1”

“And all the threading”

“All stitched to the same root paths when they intersect”

A partial proposed result is not a completed field. Current record transactions
can verify their actual returned values and preserve root relations. Complete
spatial placement, inherited motion and the corresponding full drawing still
require their source-bound derivation and witnesses.

## Conversation

The mechanism is the model. Input retains its source, address, whole context,
Difference, relations and receipts. It is not automatically intent, command,
authority, truth or NEXT. Fixed English triggers and authored fallback replies
are not substitutes for the interpretation and reply-composition mechanism.
Those reductions remain unbound in this implementation; new input is retained
without manufacturing an assistant answer.
