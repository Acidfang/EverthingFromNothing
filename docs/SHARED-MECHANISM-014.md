## Executable dependency path

Provider return or explicit user choice → existing source-bound proposal → issued staged state → shared compiled-C value-return windows → original actual DOM transition/value readback → atomic engine commit → scene/workspace addressed subscriptions. Discovery additionally runs its supplied packet membership and parent links through the recursive C contract before constructing a proposal.

`src/model/ei-mechanism.ts` pins an immutable frame and uses the same occurrence shape at every recursive child. Actual independent Node worker threads execute the same packaged worker module; output order follows the pinned source rather than completion order. Parallelism is bounded at two. The serial backend executes the identical C module. A worker is a transport/execution context, not additional semantic authority.

`src/model/ei-operation-mechanism.ts` covers every producer entering the common staged-operation boundary, including conversation capture, Guide, sow/nurture, media retention, environment, public sync, device encounters, authored relations and ordinary edits. Up to four affected values plus the producer form each window. Links explicitly mean transaction membership, not spatial or inferred semantic adjacency. The existing unified transition verifies source-defined parent/relation records. Proposed values remain proposed until the independent rendered commit succeeds. Cancelling or replacing the source invalidates pending returns.

Each actual common-core runtime return is retained as a correlated mechanism ticket in session export/import and opt-in atomic local saves. The ticket has committed:false because the core return itself does not commit the field; the separate engine receipt identifies admission. Imported tickets are historical records, not fresh execution or external attestation. Canonical engine receipts retain the source, exact candidate, patches and rendered checks; discovery receipts also retain their compact recursive-core result binding. Existing 512-ticket/session-byte limits reject overflow without eviction.
