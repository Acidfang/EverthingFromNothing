# First Act Explorer Specification

## Public promise

The explorer lets a visitor perform one declared operation and inspect every
result that operation generated:

\[
\boxed{
\text{First Difference}
\rightarrow
\text{one shared tick}
\rightarrow
\text{recursive Resolution}
}
\]

It is an executable mathematical model, not a claim that the current kernel is
established physics.

Every visible statement is classified as:

```text
GIVEN       supplied starting statement
DERIVED     forced by declared parents
SELECTED    formal choice making the operation executable
GENERATED   calculated output of the selected kernel
UNRESOLVED  interpretation not derived by the kernel
```

Generated output and selected ancestry are separate facts. A generated relation
may still be blocked from external physical comparison.

## Initial state and chronology

```text
WAS  -> no represented Difference
IS   -> one First Difference at the relative origin
NEXT -> absent until calculated
```

One tick freezes the complete `WAS/IS` pair, calculates every addressed
relation from that snapshot, then commits the next complete field together.
Local iteration order does not create chronology inside the tick.

## Exploration

The same explorer state supports tick and WAS navigation, complete-whole inward
and outward navigation, six-Face spatial navigation, recursive query depth,
relation selection, causal explanation and complete JSON export.

Changing grain or spatial address does not change the shared Act. Entering a
whole selects one complete child and rebases its entire support; it is not a
point-centered crop.

## Exact first whole projection

The selected kernel generates:

```text
6 complete child wholes
6 outward presentations per child
36 total presentations
19 addressed containing-grain relations
12 double-arrival Same resolutions
1 central six-arrival Same resolution
6 residual outward Differences
```

The normalized projection is invariant through completed levels 1–8 in the
automated tests.

## Unbounded relation

Finite query prefixes obey:

\[
Q_d\subset Q_{d+1}.
\]

Every frontier remains expandable through inward grain, outward grain, six
spatial Faces, `WAS`, and `NEXT`. A finite computation boundary is never
labeled as the boundary of the model.

## Causal explanation

Every selected relation exposes its address, arrival count, contributors,
`WAS` state where applicable, Same/Different result, causal explanation,
`GENERATED` status, ancestry statuses, external-comparison gate and provenance
node IDs.

## Publication gates

The public repository is complete only when:

1. The First Difference is its only nonempty seed.
2. A tick reads one immutable snapshot and commits together.
3. Reverse update exactly recovers the prior field.
4. Results and ledgers are independent of collection insertion order.
5. Grain and spatial navigation preserve the shared Act.
6. Entering a child rebases a complete whole without cropping.
7. Deeper recursive queries preserve every earlier prefix.
8. The exact 36-to-19 projection is reproduced.
9. Every visible claim exposes provenance.
10. Unresolved physical identity cannot be promoted.
11. Interactive terminal exploration works.
12. Graphical exploration supports pointer and keyboard.
13. Graphical exploration remains usable on desktop and narrow screens.
14. A production build succeeds without runtime network access.
15. Repository scope, license and public limitations are explicit.
16. Automated checks run on GitHub.
