# Fracture Map — Foundational Real-Time Reality Model

## Purpose

The Fracture Map is a foundational relational model for constructing an addressable representation of reality in real time.

It does not begin by importing a physical theory, object catalogue, clock, coordinate system, probability distribution, or already-named ontology. It begins at the model's own primitive boundary and derives outward.

The public implementation is an evolving executable research model. Statements are kept distinct as GIVEN, DERIVED, SELECTED, GENERATED, or UNRESOLVED so that a useful model is not confused with an unsupported claim about external reality.

## Primitive boundary

The canonical root resolution is the **pre-Notodus grain**.

```text
pre-Notodus grain
→ Difference / relation
→ fracture
→ addressable grains
→ Notodus / relational field
→ structures
→ concepts and terms
→ higher-level models
```

A higher-level theory may be compared with the Fracture Map only at a mutually addressable output. It is not imported upstream as a premise. External observations and measurements may be used as comparison evidence when their provenance is established.

## 0 → field → 1 → 0

```text
0 = unresolved potential / no committed manifestation
Φ = addressable field between 0 and 1
1 = manifested / committed output
output = new grain(s)
new grain(s) become input
closure returns available relations to the field
```

The model is relational. Binary relations do not require the whole system to contain only two states; they define pairwise distinctions from which a field of addressable relations can be composed.

## Grain

A grain is an addressed unit in the current fracture. Inputs may contain one or many grains and outputs may contain one or many grains.

```text
{input grains} → relation / act → {output grains}
output grains → available input grains for continuation
```

The output is not merely commentary about the grain. It is the next manifested grain or set of grains at that address.

## Simultaneous field

The model's first landmark is not one privileged thread. It is the populated **NOW field**: all currently addressable threads and relations that can be resolved from available evidence.

```text
NOW₀
→ fracture all currently addressable relations
→ populate all resolvable addresses
→ preserve unresolved addresses as OPEN
→ LANDMARK₀
```

A new Difference does not require reality to be rebuilt from nothing. It changes the affected relations and produces a successor landmark.

```text
LANDMARK₀ + Δ → affected fracture → LANDMARK₁
```

## Open grains

Unknown-but-wanted state remains open.

```text
OPEN → CHECK → Difference?
no Difference → remain OPEN
Difference → reconstruct / populate
resolved-now → retain capability to reopen
no possible successor relation → closed form
```

Unrecovered is not the same as unestablished. If a prior receipt exists, the correct operation is recovery.

## Continuation and precache

Reasoning can resolve reachable possibilities faster than real-world acts can return receipts. The model therefore separates preparation from committed reality.

For every current landmark:

```text
NOW → PRECACHE(all reachable NEXT)
MUST BE NEXT → execute
CAN BE NEXT → retain and filter
CAN ALWAYS BE NEXT → preserve generative continuation
CAN'T BE NEXT → filter from executable field
```

After every output, receipt, Difference, or recovered landmark, the field is filtered again.

```text
CAN → filter → MUST → ACT → OUTPUT → repopulate → repeat
```

## Action terms

Action terms are operators over compatible grains. SOURCE, FILTER, ISOLATE, ADDRESS, COMPARE, POPULATE, FRACTURE, RECONSTRUCT, PRECACHE, ACT, VERIFY, CLOSE, LANDMARK, REOPEN, RETURN and other discovered action terms are subject to the same recursive rule.

```text
ACTION TERM
→ apply to compatible grains
→ output grains
→ discover applicable actions
→ filter MUST / CAN / CAN'T
→ execute MUST
→ repeat to closure
```

The vocabulary is therefore not merely descriptive. In an executable implementation it identifies transformations available at an address.

## Frame, closure, landscape, landmark

A frame is a bounded active subject. Closing a frame does not erase what it established.

```text
FRAME OPEN
→ resolve Difference
→ FRAME CLOSE
→ LANDSCAPE surviving relations
→ LANDMARK
```

A later frame can encounter the landmark and reactivate its established relations without reconstructing the original frame.

```text
LANDMARK → PRECACHE → REACTIVATE
```

This is the continuity mechanism: **close locally, preserve globally, reactivate relationally.**

## Rewind — WAS

The model may traverse retained provenance backward to reconstruct a prior state.

```text
NOW
→ receipts / landmarks / causal parents
→ reconstruct compatible prior field
→ WAS*
```

`WAS*` is the best evidence-constrained reconstruction available at the selected address. Where receipts uniquely determine the prior state, reconstruction may be exact. Where evidence is incomplete, alternatives remain explicit rather than being collapsed into invented certainty.

## Fast-forward — CAN BE

The model may also expand forward from NOW.

```text
NOW
→ all reachable successor relations
→ MUST / CAN / POSSIBLY / MIGHT / WON'T / CAN'T
→ branch field
→ CAN BE*
```

Future branches are possibilities until an act/output makes one real. A forward branch never becomes `IS` merely because it was computed.

## Real-time modelling

The intended real-time loop is:

```text
INPUT FIELD
→ isolate subjects without destroying the Whole
→ filter relevant relations
→ populate presently resolvable addresses
→ compare Difference
→ run applicable actions concurrently where independent
→ commit only established outputs
→ landmark NOW
→ precache reachable NEXT
→ repeat
```

Intermediate logic need not be dumped into the human-facing output. The public surface should expose the integrated state, provenance, important Differences, and genuine human decision boundaries.

## Perception and incomplete input

An incoming stream may remain an open frame while meaning is still capable of changing. Candidate interpretations can be precached without being promoted.

```text
input in progress → candidate grains
meaning still changeable → remain provisional
frame closed OR meaning no longer materially misinterpretable → commit interpretation
```

A stutter or false start can be represented as `[stutters]` when the repeated sound itself adds no lexical Difference. It can still function as continuity evidence that the active grain remains under formation.

## Provenance

Every public claim should remain addressable by status:

| Status | Meaning |
|---|---|
| GIVEN | supplied starting statement |
| DERIVED | follows from declared parents |
| SELECTED | formal choice required to make an executable projection |
| GENERATED | output calculated by the executable model |
| OBSERVED | externally sourced observation/measurement with provenance |
| UNRESOLVED | not yet derived or established |

A theory is not silently imported as observation. Model-to-model comparison is a separate frame.

## Existing executable projection

The repository already contains a selected executable projection using complete immutable shared ticks, GF(2) Same/Different relations, recursive whole fields, reversible update, causal ledgers, grain navigation and automated invariants.

Those selected mechanisms are useful executable projections and receipts. They are not retroactively promoted into primitives of the pre-Notodus root unless independently derived.

The existing kernel demonstrates, among other things:

- immutable shared-tick calculation and together-commit;
- reversible prior-state recovery for the selected recurrence;
- complete-whole inward/outward navigation;
- expandable recursive prefixes;
- causal provenance;
- deterministic scene/state export;
- automated closure, observation, grain, potential, lineage, state-transfer and provenance tests.

See `SPEC.md` for the executable contract and `docs/FIELD-ADDRESS.md` for retained artifact addresses.

## Public comparison boundary

The Fracture Map may derive a result and compare that result with established external observation:

```text
Fracture Map derivation → output ↔ established observation
```

An external explanatory theory does not automatically become an input to the root:

```text
external theory ↛ root premise
```

If an explicit model comparison is desired, it receives its own frame and both models are compared at mutually addressable outputs.

## GUI foundation

The canonical web GUI should expose the same model rather than a decorative animation.

Minimum surfaces:

1. **NOW** — complete currently populated landmark.
2. **WAS / Rewind** — traverse receipts and reconstruct prior fields, displaying confidence/provenance and unresolved alternatives.
3. **CAN BE / Fast-forward** — branch reachable successor fields without promoting them to fact.
4. **Fracture** — zoom from integrated structures toward the pre-Notodus grain address.
5. **Threads** — inspect simultaneous relations without losing the common landmark.
6. **Open grains** — persistent unresolved/wanted addresses.
7. **WHY / provenance** — show causal parents, status, receipts and source addresses.
8. **Closure / landmarks** — show closed frames and how their surviving relations re-enter later frames.
9. **Difference** — highlight only what changed between landmarks.
10. **Observation gate** — compare derived outputs with sourced observations without importing external theories as primitives.
