# Limitations

This repository demonstrates an executable mathematical model. It does not
establish that the model is a physical theory.

1. The First Difference is supplied as the First Act; it is not generated by a
   deterministic update of the empty state.
2. Six Face relations are selected. Their uniqueness is not proved.
3. GF(2) parity is selected. Its uniqueness is not proved.
4. The symbolic infinitesimal rotation is not yet an executable magnitude.
5. A recursive query describes permitted relations; it does not allocate an
   actually infinite physical field.
6. The current projection produces one scale-invariant class, not distinct
   atomic classes.
7. No generated level is identified with a measured atom, particle, cosmic
   web, black hole, gravitational field, or other physical object.
8. No physical units or fitted constants occur in the public kernel.
9. Visual similarity is not accepted as physical equivalence.
10. External comparison remains blocked wherever selected or unresolved steps
    occur in the causal ancestry.

Contributions should reduce a limitation with a derivation, test,
counterexample, or more general kernel—not by renaming generated structures.
