# Contributing

Every new visible claim must declare:

```text
status
causal parents
reason
executable evidence
verification
```

Use `GIVEN`, `DERIVED`, `SELECTED`, `GENERATED`, or `UNRESOLVED`. Do not promote
a selected formalization or generated resemblance into a physical identity.

A kernel change must test deterministic immutable-snapshot update, collection
order independence, reversal or explicit information loss, recursive-prefix
preservation, and provenance of new output fields. Declare every new seed,
constant, unit, coordinate relation, or matching tolerance.

Interface work must preserve one shared Act across grain navigation,
complete-whole entry rather than cropping, an expandable frontier,
`WAS / IS / NEXT`, selectable ledger entries, visible provenance, and keyboard
plus narrow-screen operation.

Run:

```sh
npm run test:model
```
